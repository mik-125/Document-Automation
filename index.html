Enable Sheets, Docs, and Drive APIs, then connect the personal Google account that owns or can open the source files.

SETUP CHECKLIST

What you need from Google Cloud

  1. Configure the Google OAuth consent screen and add your account as a test user.
  2. Create a Web application OAuth client with redirect URI http://127.0.0.1:8000/api/google/oauth/callback.
  3. Download its JSON outside this repository and set GOOGLE_OAUTH_CLIENT_FILE.
  4. Enable Google Sheets API, Google Docs API, and Google Drive API.
  5. Click Connect Google account. Brightline creates a private Brightline Reports folder in My Drive.
