SETUP CHECKLIST

What you need from Google Cloud

  1. Create one service account and download its JSON credential outside this repository.
  2. Set GOOGLE_SERVICE_ACCOUNT_FILE when starting Brightline.
  3. Enable Google Sheets API, Google Docs API, and Google Drive API.
  4. Share the source Sheets and Docs with the service-account email.
  5. Use a dedicated report Shared Drive or limited-access folder whose members are authorized for student data, give the service account Content Manager access, then test its link above.
